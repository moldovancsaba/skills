## Rules

- skills must not contradict the repository rulebook
- skills must not teach agents to build hot product routes through client waterfalls when server/bootstrap or prepared projections are available
- skills must respect the local-AI authority boundary
- skills must tell agents to prefer prepared read models, narrow payloads, deferred non-critical hydration, and route profiling before blind trimming
- if a new skill changes how agents should implement product functions, the AI-brain docs must be updated in the same work
