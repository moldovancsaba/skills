Every marketing document must contain:
- Title
- Owner
- Purpose
- Status (Draft | In Review | Approved | Active | Superseded | Archived)
- Last Updated
- Relevant Team
- Source of Request
- Linked Workflow
- Definition of Done
- Related Dependencies
- Next Review Date

## 4. Document Lifecycle

### 4.1 Creation
- Use approved templates
- Follow naming convention
- Include all required fields
- Store in correct folder

### 4.2 Review and Approval
- Draft status for initial creation
- In Review status for stakeholder review
- Approved status after CMO approval
- Active status when in use

### 4.3 Updates
- New version created for material changes
- Old version archived, not deleted
- Change log documented
- Stakeholders notified

### 4.4 Archival
- Superseded documents moved to 09_archive/
- Archived documents renamed with _archived suffix
- Archive index maintained
- Retention period: 3 years
