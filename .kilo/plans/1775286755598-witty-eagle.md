# Checklist Architecture: Online + Local AI System

## Problem
- Current system uses template-based "Brain" - no real AI
- Paperclip not connected
- Need real AI that learns from user feedback
- Need seamless pipeline, no manual "Generate" button

## Solution: Continuous Pipeline Architecture

### User Experience (What We Want)
- User drops ANY info anytime: products, competitors, ideas, treats, observations
- No "Generate" button - it's a continuous workflow
- System learns over time from ALL feedback
- NBA appears when quality is ready (not real-time)
- AI connects dots humans miss
- "Looks-like-realtime" but quality-first

## Trigger Logic (NEW DATA ONLY)

1. **Track last sync timestamp** in database or file
2. **Query for new data since last sync**:
   ```sql
   SELECT * FROM "Product" WHERE "createdAt" > $lastSync
   UNION ALL
   SELECT * FROM "Customer" WHERE "createdAt" > $lastSync
   UNION ALL
   SELECT * FROM "Competitor" WHERE "createdAt" > $lastSync
   ```
3. **Only run AI if new data exists** - skip if no new data
4. **Update lastSync after processing**

## Smarter Deduplication

1. **Normalize titles** (lowercase, remove common words like "the", "and", "for", "with")
2. **Tokenize and compare** using simple Jaccard similarity
3. **Threshold**: 0.7 similarity = duplicate
4. **Example**:
   - "Boost SEO Strategy" ≈ "SEO and Keyword Strategy" → duplicate

```js
function similarity(a, b) {
  const tokenA = normalize(a).split(' ');
  const tokenB = normalize(b).split(' ');
  const common = tokenA.filter(t => tokenB.includes(t));
  return common.length / Math.max(tokenA.length, tokenB.length);
}

function normalize(s) {
  return s.toLowerCase()
    .replace(/^(a|an|the|and|or|for|with|to|of)\s+/g, '')
    .replace(/[^\w\s]/g, '');
}
```

## Pipeline Complete Flow

```
Polling (300s)
    ↓
Check for new data since lastSync
    ↓ (no new data) ──→ Skip, wait for next poll
    ↓ (new data exists)

    ↓
Generate 3 NBA recommendations
    ↓
Smarter dedup (Jaccard ≥ 0.7) against ALL existing
    ↓

    ↓
Update lastSync timestamp
    ↓
User sees new NBA on next refresh (600s)
```
