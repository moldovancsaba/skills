## Report Types

| Report | Frequency | Audience | Purpose |
|--------|----------|----------|---------|
| Delivery Status Report | Per milestone or weekly | Customer | Current delivery status, progress, next steps |
| Outcome Report | Monthly or per engagement phase | Customer | Value delivered, outcomes achieved, feedback summary |
| Issue Summary | Per issue resolution or monthly | Customer | Open issues, resolved issues, trends |
| Renewal Readiness Report | 60 days before renewal | Customer + CEO | Account health, usage summary, renewal recommendation |

## Reporting Workflow

### Stage 1: Data Collection
- Gather delivery data, issue logs, feedback records, and engagement metrics
- Verify data accuracy against customer record
- Identify key highlights and areas of concern

### Stage 2: Report Preparation
- Use approved report template
- Populate with verified data
- Include: executive summary, detailed status, risks/blockers, next steps
- Review for accuracy and completeness

### Stage 3: Internal Review
- CCO reviews report before customer delivery
- Flag any sensitive or escalatory content for CEO awareness
- Confirm report aligns with customer communication standard

### Stage 4: Delivery
- Send report to customer via agreed channel
- Include clear summary in delivery communication
- Request acknowledgment or schedule review call if needed

### Stage 5: Follow-Up
- Track customer response or questions
- Address any concerns raised by the report
- Log all follow-up communications

### Stage 6: Archive
- Store final report in customer record
- Update report index for the account
- Flag any action items for tracking

## Definition of Done

Client reporting is not done unless:
- Report data is verified and accurate
- Report follows approved template and standard
- Report is delivered to customer
- Delivery is logged in customer record
- Customer acknowledgment or response is tracked
- Report is archived in correct location
- Any action items are identified and assigned
