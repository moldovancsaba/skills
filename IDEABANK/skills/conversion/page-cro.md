# page-cro: Marketing Page Conversion Optimization

## When to Use This Skill

Use when user wants to optimize, improve, or increase conversions on any marketing page — including homepage, landing pages, pricing pages, about pages, or feature pages.

## Framework

### Step 1: Understand the Page
- What is the page URL and purpose?
- What is the current conversion goal?
- Who is the target audience?

### Step 2: Apply CRO Principles
- Headline testing (benefit-focused vs. feature-focused)
- CTA placement and copy
- Social proof integration
- Risk reversal elements

### Step 3: Generate NBA Recommendations
- Priority changes based on impact
- A/B test suggestions
- Quick wins vs. longer experiments

## Expected Outputs

- NBA item with specific changes to implement
- Impact estimate (ICE score)
- Test hypotheses for A/B tests
