# Checklist: Issue Handling

**Owner:** CCO
**Purpose:** Ensure every customer issue is handled consistently and completely
**Cadence:** Per issue
**Last Updated:** 2026-04-01
**Status:** Active

---

### Steps

- [ ] Receive issue from customer through approved channel
- [ ] Log issue with timestamp, customer, and description
- [ ] Assign severity level (P1-P4)
- [ ] Acknowledge receipt to customer within SLA
- [ ] Classify issue type (technical, delivery, scope, billing, other)
- [ ] Gather relevant context (history, communications, records)
- [ ] Identify root cause or likely cause
- [ ] Execute resolution or escalate per Escalation Matrix
- [ ] Confirm resolution with customer
- [ ] Log all actions and communications
- [ ] Capture feedback on support experience
- [ ] Close issue record with resolution summary
- [ ] Flag systemic issues for review

### Completion Criteria

This checklist is complete when all steps are checked and the Definition of Done is satisfied.

### Definition of Done

- Issue is resolved or escalation path is documented
- Customer is informed of status and next steps
- All communications are logged
- Feedback is captured where relevant
- Product or technology implications are routed to the correct team
- Issue record is complete and closed or clearly marked as in-progress
