# Checklist Architecture: Online + Local AI System

## Problem
- Current system uses template-based "Brain" - no real AI
- Paperclip not connected
- Need real AI that learns from user feedback
- Need seamless pipeline, no manual "Generate" button

## Solution: Continuous Pipeline Architecture

### User Experience (What We Want)
- User drops ANY info anytime: products, competitors, ideas, treats, observations
- No "Generate" button - it's a continuous workflow
- System learns over time from ALL feedback
- NBA appears when quality is ready (not real-time)
- AI connects dots humans miss
- "Looks-like-realtime" but quality-first

## Implementation Plan

### Phase 1: Webhook Trigger System
1. Create `/api/webhook/trigger` endpoint in checklist
2. Called when ANY new data is added (product, customer, competitor, idea)
3. Calls local system to start sync pipeline

### Phase 2: Local Sync Pipeline (in mvp-factory-control)
1. Create `scripts/checklist-sync/sync.js` script:
   - Receives webhook call
   - Pulls all new data from Neon since last sync
   - Updates local PostgreSQL mirror
   - Updates vector embeddings (for semantic search)
   - Triggers AI processing

2. Add to mvp-factory-control in control_mvp.py

### Phase 3: AI Brain with Learning
1. Create `scripts/checklist-sync/brain.js`:
   - **Model priority**: gemma3:1b → llama3.2:3b → qwen2.5:3b → deepseek-r1:1.5b
   - Read ALL data (not just recent)
   - Read ALL feedback history
   - **Learning**: Analyze patterns in accept/decline + annotations
   - **Generation**: Use context + learning to create NBA
   - **Quality**: 3-5 best recommendations only

### Phase 4: Seamless Online UI
1. Remove "Brain" and "Local AI" buttons
2. Auto-refresh NBA list every 30 seconds
3. Show "Analyzing..." indicator when AI is processing

### Phase 5: Remove Legacy Code
1. DELETE `/api/brain/route.ts` (template-based)
2. DELETE template logic from NBA generation

## New Data Pipeline

```
USER ACTION          →    ONLINE DB            →    WEBHOOK        →    LOCAL SYNC
─────────────────────────────────────────────────────────────────────
Add product        →    INSERT            →    POST /trigger →    Pull new data
Add customer       →    INSERT            →    POST /trigger →    Update mirror  
Add idea           →    INSERT            →    POST /trigger →    Vector embed
Give feedback     →    INSERT            →    POST /trigger →    Learning++
```
