# Flashcard NBA Pipeline - Implementation Plan

## Goal

1. Generate missing flashcards from existing company data (products, customers, competitors)
2. Have local agent create flashcards by visiting/analyzing sources
3. Use flashcards as primary source for NBA generation instead of raw data

---

## Current Architecture

### Flashcards (`src/lib/flashcards.ts`)
- `syncBootstrapFlashcards(companyId)` - creates flashcards from products/customers/competitors
- `listCompanyFlashcards(companyId)` - returns active flashcards with sources
- Already exists and works

### Local Agent (`src/app/api/agent/local/route.ts`)
- Currently reads raw products/customers/competitors directly
- Does NOT use flashcards
- Uses DeepSeek-R1 model via Ollama

## Implementation Plan

### Step 1: Add Flashcard Sync Endpoint

Create `src/app/api/flashcards/sync/route.ts`:

```ts
export async function POST(request: NextRequest) {
  const { companyId } = await request.json();
  
  if (companyId) {
    await syncBootstrapFlashcards(companyId);
    return NextResponse.json({ success: true, companyId });
  }
  
  // Sync all companies
  const companies = await prisma.company.findMany();
  for (const company of companies) {
    await syncBootstrapFlashcards(company.id);
  }
  return NextResponse.json({ synced: companies.length });
}
```

const flashcards = await prisma.flashcard.findMany({
