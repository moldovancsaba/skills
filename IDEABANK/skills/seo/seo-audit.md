# seo-audit: Technical and On-Page SEO Audit

## When to Use This Skill

Use when user wants to audit, review, or diagnose SEO issues on their site. Also use when user mentions "SEO audit", "check rankings", or "improve search visibility".

Source: coreyhaines31/marketingskills/skills/seo-audit

## Framework

### Step 1: Crawl Analysis
- Index coverage
- Core web vitals
- Crawl errors

### Step 2: On-Page Audit
- Title tags and meta descriptions
- Heading structure
- Internal linking
- Content quality

### Step 3: Technical SEO
- Schema markup
- XML sitemaps
- Robots.txt
- Page speed

### Step 4: Generate NBA
- Critical fixes (high ICE)
- Content opportunities
- Technical improvements

## Expected Outputs

- List of SEO issues with severity
- NBA items for fixes
- Content optimization suggestions
