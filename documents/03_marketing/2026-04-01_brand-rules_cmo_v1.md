## 1. Brand Voice

### 1.1 Voice Attributes
| Attribute | Description | Example |
|-----------|-------------|---------|
| **Clear** | Simple, direct language | "Turn evidence into governed cards" not "We provide comprehensive solutions" |
| **Actionable** | Focused on next steps | "Download the template" not "Learn more about our offerings" |
| **Accountable** | Takes ownership | "We will deliver" not "We aim to deliver" |
| **Professional** | Respectful, competent | "We recommend" not "You should" |
| **Simple** | Avoids complexity | "Use this" not "Utilize this solution" |

### 1.2 Tone by Context
| Context | Tone | Example |
|---------|------|---------|
| **Website** | Confident, clear | "Evidence-backed intelligence for operating Units" |
| **Email** | Helpful, direct | "Here's the template you requested" |
| **Social** | Engaging, insightful | "3 mistakes to avoid when documenting processes" |
| **Sales** | Consultative, focused | "Let's understand your challenges first" |
| **Support** | Patient, solution-focused | "Here's how to fix that" |

## 2. Visual Identity

### 2.1 Logo Usage
- Primary logo: check wordmark with checkmark icon
- Minimum size: 120px width for digital, 1 inch for print
- Clear space: Minimum 1x logo height on all sides
- Background: White or light neutral colors only

### 2.2 Color Palette
| Color | Hex | Usage |
|-------|-----|-------|
| **Primary** | #2E7D32 | Headlines, buttons, primary elements |
| **Secondary** | #1565C0 | Links, secondary elements |
| **Accent** | #FF8F00 | CTAs, highlights |
| **Neutral Dark** | #212121 | Body text |
| **Neutral Light** | #F5F5F5 | Backgrounds, cards |

### 2.3 Typography
| Type | Font | Weight | Size |
|------|------|--------|------|
| **Headlines** | Inter | Bold | 32px-48px |
| **Subheadlines** | Inter | Semi-Bold | 24px-32px |
| **Body** | Inter | Regular | 16px |
| **Small** | Inter | Regular | 14px |
| **Caption** | Inter | Light | 12px |

### 2.4 Imagery Style
- **Photography:** Clean, simple compositions
- **Illustrations:** Minimalist line art or flat design
- **Icons:** Consistent stroke weight, simple forms
- **Charts:** Clean, minimal, focus on data

## 3. Writing Standards

### 3.1 Grammar and Style
- Use active voice
- Use present tense
- Use Oxford comma
- Use sentence case for headlines
- Use title case for navigation
- Use numerals for numbers 10 and above
- Use % symbol, not "percent"

### 3.2 Terminology
| Term | Use | Do Not Use |
|------|-----|------------|
| **checklist** | Lowercase, one word | Check list, CheckList, Checklist |
| **solution** | For our deliverables | Product, offering, service |
| **client** | For our customers | Customer, user, buyer |
| **document** | For our outputs | Deliverable, artifact |
| **system** | For repeatable processes | Process, workflow (unless technical) |

### 3.3 Content Structure
- Every piece of content must have:
  - Clear headline
  - Problem statement
  - Solution
  - Proof point
  - Clear call to action

## 4. Brand Compliance Checklist

Before publishing any branded content:

- [ ] Voice matches brand attributes
- [ ] Tone matches context
- [ ] Logo used correctly
- [ ] Colors follow palette
- [ ] Typography follows standards
- [ ] Imagery matches style
- [ ] Grammar follows standards
- [ ] Terminology is correct
- [ ] Content structure is complete

## 5. Brand Violation Examples

### 5.1 Voice Violations
- "Our comprehensive solutions leverage cutting-edge technology" (too complex)
- "We think maybe this could help" (not accountable)
- "Utilize our platform" (not simple)

### 5.2 Visual Violations
- Logo on dark backgrounds
- Using incorrect colors
- Different fonts in same document
- Low-quality or off-brand imagery
